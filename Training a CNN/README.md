# 🧠 CIFAR-10 Image Classification Using Convolutional Neural Networks (CNN)
This project implements and trains a Convolutional Neural Network (CNN) to classify images from the CIFAR-10 dataset into 10 everyday object categories such as airplanes, cars, ships, and animals.

The goal of this study is to explore the effectiveness of CNN architectures in supervised image classification and evaluate the model’s performance using common deep-learning metrics.
